# Development Scripts

This directory contains utility scripts for development and manual verification.

## Available Scripts

- `validate_openai_key.py`: Verify OpenAI API key is valid.
- `verify_audio_capture.py`: Test audio capture functionality.
- `verify_stage_2_4.py`: Verify Stage 2.4 database models.
- `verify_stage_3.py`: Verify Stage 3 document processing.
- `verify_stage_4.py`: Verify Stage 4 AI integration.

## Usage

Run these scripts from the project root with the virtual environment activated:

```bash
python -m backend.scripts.validate_openai_key
```
